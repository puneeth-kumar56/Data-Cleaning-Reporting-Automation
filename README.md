# Data Cleaning & Reporting Automation 🎓📊

An end-to-end Python project that **automatically generates**, **cleans**, **analyses**, and **reports** on a synthetic student academic performance dataset using Excel files and professional charts.

---

## 📌 Project Overview

This project demonstrates a complete data-quality pipeline:

| Stage | What happens |
|-------|--------------|
| **Generate** | Creates a messy 130-row Excel dataset with missing values, duplicates, inconsistent text, and invalid numbers |
| **Clean** | Removes duplicates, fills missing values, normalises text, flags invalid entries |
| **Analyse** | Computes department stats, grade distribution, attendance analysis, and correlations |
| **Report** | Saves a 7-sheet Excel workbook, 6 PNG charts, and a plain-text summary |

---

## 🎯 Project Objectives

- Automate data cleaning without manual intervention
- Demonstrate industry-standard data-quality handling
- Produce professional Excel reports with formatting
- Generate meaningful visualisations

---

## ✨ Features

- ✅ Generates synthetic data with **intentional** quality issues
- ✅ Handles **missing values** per-column with documented strategies
- ✅ Removes **exact duplicate** rows; reports duplicate Student_IDs separately
- ✅ **Standardises** department, gender, and city text
- ✅ **Validates** numeric ranges; flags out-of-range values (does NOT invent values)
- ✅ **Validates** email formats; flags invalid ones
- ✅ Recalculates Total_Marks and Grade from clean component marks
- ✅ Produces a **7-sheet Excel report** with charts embedded
- ✅ Runs a **10-point verification suite** at the end
- ✅ Fully reproducible; re-running produces consistent results

## 📂 File-by-File Explanation

### `src/generate_dataset.py`
Generates 120 synthetic student records and injects:
- **Missing values** in 11 columns (4–8 % each)
- **10 duplicate rows** (exact copies of existing rows)
- **Inconsistent department names** (`cse`, `CSE`, `Cse`, ` CSE`)
- **Inconsistent gender** (`Male`, `MALE`, `M`, `male`)
- **Dirty city names** (`Bombay` vs `Mumbai`, `Bangalore` vs `Bengaluru`)
- **Invalid ages** (negative, > 140)
- **Attendance > 100 %**
- **Malformed emails** (missing `@`, double `@@`, no domain)

### `src/data_cleaning.py`
Runs the cleaning pipeline and returns a `CleaningResult` dataclass:

| Step | Action |
|------|--------|
| A – Load | Read Excel, display shape and dtypes |
| B – Missing values | Numeric → median; categorical → mode or "Unknown"; emails → keep NaN |
| C – Duplicates | Drop exact duplicates; report duplicate Student_IDs separately |
| D – Standardise text | Strip spaces; map department/gender/city to canonical forms |
| E – Validate numerics | Flag out-of-range → NaN; refill with column median; recalculate Total_Marks |
| F – Validate emails | Flag malformed → NaN |
| G – Grade recalc | Recompute Grade from clean Total_Marks |
| H – Save | Write formatted Excel with bold headers, alternating rows, filters, frozen row |

### `src/data_analysis.py`
Computes and returns an `AnalysisResult` dataclass containing:
- Scalar stats (averages, min, max, counts)
- Department-level aggregations
- Grade distribution with percentages
- Attendance bins (< 50 %, 50–60 %, …, 85–100 %)
- Pearson correlation between attendance and total marks

### `src/generate_report.py`
- Generates **6 PNG charts** using matplotlib/seaborn
- Builds a **7-sheet Excel workbook** with openpyxl
- Writes a **plain-text summary** file
- Embeds charts into the "Charts" worksheet

### `main.py`
Orchestrates all four stages; runs a 10-point verification suite; prints a final execution summary.

## 🧹 Data Cleaning Methodology

### Missing Value Strategy

| Column | Strategy | Reason |
|--------|----------|--------|
| Age, Attendance_Percentage, *_Marks, Total_Marks | Median | Robust to the outliers we deliberately introduced |
| Gender, Department, Grade | Mode | Most frequent value preserves distribution |
| City | "Unknown" | Avoids wrong geographic assignment |
| Email | Retain NaN | Validated separately; no safe default |
| Student_ID, Student_Name | Not filled | Must remain unique identifiers |

### Invalid Value Strategy
- Out-of-range numeric values are set to `NaN` (flagged, not silently replaced).
- After flagging, `NaN` values in numeric columns are refilled with the column median.
- Invalid emails are set to `NaN`.
- The cleaning log records every action with exact counts.

## 🐛 Common Errors & Solutions

| Error | Solution |
|-------|----------|
| `ModuleNotFoundError: No module named 'pandas'` | Activate venv: `.\venv\Scripts\Activate.ps1`, then `pip install -r requirements.txt` |
| `PermissionError: [Errno 13]` on Excel file | Close the file in Excel, then re-run |
| `FileNotFoundError: Raw dataset not found` | Run `python main.py` from the project root (not from inside `src/`) |
| `Set-ExecutionPolicy` blocked | Run PowerShell as Administrator and re-run the Set-ExecutionPolicy command |
| Charts not appearing | Ensure `matplotlib` is installed and `reports/charts/` directory is writable |
